# Zubair MD — Professional Portfolio & Interactive Showcase

A modern, high-performance, single-file portfolio website built with semantic HTML5, Tailwind CSS, and vanilla JavaScript. Designed for both technical recruiters and non-IT visitors with an interactive perspective switcher, live project links, and built-in mini-games.

## ✨ Key Features
- **3-Way Perspective Switcher**: Instantly toggle between **Overview** (Clean summary), **Candid & Witty** (Relatable dev humor), and **Technical Specs** (Engineering deep dive).
- **Light Black Editorial Theme**: Styled with a calm, easy-on-the-eyes dark graphite surface (`#18191C`) and a 1-click surface toggle.
- **Verified Live Projects**: Direct access to **EduLib Hub** and **Hospital Review Assistant** with quick peek summaries.
- **The Daily Spark Lounge**: Interactive mini-games (Word Unscramble, Spot the Impostor, 2 Truths & 1 Lie, Spin a Good Vibe) powered by a non-repeating shuffle engine.
- **AI Twin & Role Fit Studio**: Interactive assistant and role-compatibility matcher.
- **Fully Responsive**: Optimized for mobile phones, tablets, and desktop displays.

## 🛠️ Tech Stack
- **Structure**: Semantic HTML5 (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling**: Tailwind CSS via CDN (Utility-first responsive design)
- **Interactivity**: Vanilla JavaScript (ES6+, DOM manipulation, Web Crypto API, `localStorage`, Web Speech API)
